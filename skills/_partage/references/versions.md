# Faits sensibles aux versions

Un seul fichier daté pour tout ce qui périme. Sans lui, les faits périmés se
dispersent et personne ne sait lesquels revérifier.

Chaque entrée porte sa date de vérification. Relire les entrées de plus de
trois mois.
