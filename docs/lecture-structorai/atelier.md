### rules/methode.md (3,8 Ko)
- Règle née d'infractions répétées dans la même semaine ; passe avant les règles de design.
- Rien ne se construit hors du dépôt : toute page destinée à un artisan sort du générateur (pas de fichier écrit à la main dans un dossier temporaire, pas de maquette isolée). Maquette validée = entre dans le dépôt le jour même (archétype + règles), sinon c'est une dette.
- Un livrable = 4 choses : code dans le dépôt, règle écrite dans rules/, contrôle dans scripts/, les trois vérificateurs de rendu (verifier-site fichier, verifier-ordinateur souris+clavier, verifier-mobile doigt) + verifier-depot avant tout. Un manquant = pas fini ; on ne dit pas que c'est fini.
- Panne racontée (14 sept. 2026) : livraison faite en listant les fichiers à la main, quatre pièces oubliées (generateur/zone-matiere.mjs, rules/methode.md, rules/web/client.md, rules/web/facture.md) ; le générateur a cassé au premier lancement, les 3 sites non refabriqués, l'artisan a reçu l'ancien fichier ; le contrôle tournait sur les vieilles pages et les déclarait bloquées pour une autre raison, masquant la vraie cause.
- Trois verrous : (1) verifier-depot.mjs suit imports, polices, règles citées, refuse si une pièce manque, avant le générateur ; (2) le lanceur s'arrête à la première erreur, une fabrication en échec n'écrase jamais un fichier déjà livré ; (3) vérificateurs sur la page qu'on vient de produire, avec sa date. « SORTIE=0 sur l'installation ne prouve rien ».
- Lire rules/web/ avant de construire. Les interdits ne sont pas une méthode (le plancher ; la méthode est dans composition.md et facture.md). On ne dit jamais qu'une chose marche sans mesure.
- Réutilisable Sitô (déploiement/tests/méthode) : livraison = dépôt entier produit par script + contrôle avant usage ; un contrôle qui s'arrête à la 1re erreur.
- Écart avec sito/rules/methode.md : sito ajoute une section « Un contrôle ne lit jamais ce que le code vient d'écrire » (mesurer le rendu, tester le contrôle sur une copie cassée exprès). Cette section est ABSENTE de la version atelier (atelier est en retard sur sito).
