- Leçons/pièges racontés :
  * Un test vert peut cacher une fonctionnalité morte en prod : AUDIT-046/047, les tests appelaient resolve_model avec un payload écrit à la main que le vrai appelant n'envoyait jamais ; l'escalade Opus était morte en production. Fix : tester EN TRAVERSANT depuis le vrai appelant (chat_service), pas en direct. Un test verrouillait même un agent fantôme « vision_ia » qui n'existait pas -> comparer au nom réel de la classe.
  * AUDIT-157 (chantier 7c) : les classificateurs d'intent (Haiku) consommaient des jetons sans être comptés ; désormais facturés sous l'agent « routage » avant l'agent réel (costs == ["routage", "<agent>"]) sur handle ET handle_stream (parité).
  * Pré-filtre mots-clés (coût nul, aucune IA) PUIS 1 classificateur IA ; repli sûr = conversation générique si IA dégradée/AUTRE. Mots du métier captés à tort par un pré-filtre spécialisé : « plafond » (chantier vs fiscal) et « électricité/tableau » (devis vs analyse photo) ont détourné des conversations en test manuel (27/07) ; fix = co-occurrence avec mot fiscal réel / garde ciblée (verbe d'analyse, photo jointe).
  * Un prompt n'est pas une garantie : la limite « 2 tours de questions max » écrite dans le prompt n'était pas respectée (3 salves observées) -> bornée EN CODE (compte des tours assistant avec « ? », au 3e tour mode direct qui force une proposition avec hypothèses).   * Garantie AI Act / « zéro envoi auto » : toute action qui part chez le client (relance) va en file « À faire » (validation humaine), jamais exécutée directement ; BLOCK quota = rien exécuté, rien incrémenté, rien loggé ; DEGRADE = exécution autorisée avec avertissement ; dépassement du cap LLM quotidien = signalé (over_cap) mais jamais de coupure.
  * Résumé du jour : chiffres réels déterministes, sans LLM, « 0 honnête », zéro invention (ligne omise si donnée None). Montants en centimes.
  * Élément manquant (photo) => message déterministe sans LLM.
- Réutilisable pour Sitô : méthode (fakes injectés, tests traversants, parité stream/non-stream, borne des tours en code, ne pas se fier au prompt), traçabilité ai_decisions de chaque tour IA, quotas par plan avec upsell, validation humaine avant tout envoi au client (ex. réponse à un avis Google publiée seulement après validation de l'artisan, déduction).
